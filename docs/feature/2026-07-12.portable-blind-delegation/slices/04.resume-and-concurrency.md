# Portable Resume and Concurrency

Extend portable start with an optional explicit Caara session identifier. Omission creates a fresh
session. Reuse binds to the same opaque driver cursor and working directory; no observation data
participates in recovery. Reject overlapping active turns for one session while independent
sessions run concurrently. Add bounded wait that returns Working without cancellation and supports
later terminal retrieval.

Verify through Agent Turn/diagnostic continuity tests and compiled service-process tests for fresh
sessions, explicit resume, repeat waits, same-session conflict, independent concurrency, and lost
session explicit recovery. Preserve driver-owned cursor opacity and structural blindness.
