# Slice 12: Antigravity portable guidance

Caara manages a marked block inside Antigravity's documented global rules file,
`~/.gemini/GEMINI.md`. The rules teach a complete blind portable-CLI workflow using the proven
cross-family `claude/sonnet` target: safe prompt files, accepted-start handling, immediate
human-only observation-link surfacing, strict capability non-inspection, bounded waits, terminal
`finalAnswer` consumption, cancellation, and session-reuse handling. Native Antigravity subagent
internals are explicitly excluded.

`caara install-antigravity-guidance` creates or idempotently refreshes only content between Caara's
begin/end markers. `caara uninstall-antigravity-guidance` removes only that block and deletes the
file only when no user content remains. Missing, duplicated, reversed, or unmatched markers fail
explicitly without modifying the document.

The opt-in real smoke procedure is
`docs/agents/smoke-testing.md`. Current smoke execution uses Markdown prompts,
installed service, and real `agy` print-mode transcript evidence rather than a native Antigravity
subagent facility.
