# Slice 11: Claude portable guidance

Caara installs an auto-discoverable personal Claude Code skill at
`~/.claude/skills/caara-delegate/SKILL.md`. The skill teaches the complete blind CLI workflow with
the real Antigravity target, immediate human-only observation-link surfacing, bounded waits,
terminal `finalAnswer` consumption, cancellation, and capability secrecy. It explicitly excludes
Claude's native subagent facility.

`caara install-claude-guidance` creates or idempotently refreshes only marker-owned content and
refuses an unmarked collision. `caara uninstall-claude-guidance` removes only that marker-owned
file. Other Claude configuration and skills remain untouched. The opt-in real smoke procedure is
`docs/agents/claude-code-portable-smoke-runbook.md`.
