# Slice 08: Claude portable delegation

## Outcome

Claude Agent SDK works through portable CLI and HTTP: first turn, explicit resume, caller-blind wait,
capability viewer, target/cwd/options forwarding, and reusable cancellation.

## Automated proof

- `src/claudeAgentSdkDriver/claudePortableDelegation.test.ts`
- Real portable router with injected turn service and fake Claude SDK boundary.
- CLI start/wait/cancel adapters exercise HTTP contracts.
- SDK requests assert cwd, model, options, and resume cursor.
- Wait excludes private reasoning activity; capability HTML contains it.
- Partial-output cancellation asserts SDK interrupt, reusable outcome, and viewer state.

## Manual proof

`docs/agents/smoke-prompts/cli-claude.md` covers the compiled provider with real
Claude authentication. Its opt-in Vitest automation proves real first/resume/cancel behavior against
an already installed user service while normal CI remains credential-, network-, and service-free.
Capability URLs remain bearer secrets.
