creates Caara turn/session identifiers and a capability URL before completion, a localhost page
renders live normalized activity, and CLI wait returns only working state or terminal final answer.

terminal and observation projections. No agent-facing observation-read route or transcript output.

Verify through direct projection tests, CLI parser/encoding tests, capability non-disclosure tests,
and a real service-process diagnostic start/view/wait blindness integration test. Then all project
