# CAARA-emrpolgn

Implement shared driver error classification.

Tests first:

- runtime `TurnFailed` preserves explicit `invalid_prompt`
- runtime transport stream failure preserves explicit `invalid_prompt`
- bare driver error construction is no longer a valid call-site pattern

Implementation:

- add explicit builders for surfaced invalid-prompt and internal server-error driver failures
- update existing bare call sites required by tests
- remove encoder-side silent driver-error `server_error` mapping

Result:

- `AgentDriverError.responseErrorCode` now required.
- `createInvalidPromptAgentDriverError` and `createServerErrorAgentDriverError` are the supported
  construction API.
- runtime encoder preserves explicit driver error codes for `TurnFailed` and runtime stream
  failures.
- validation: `bun lint`; `bun run typecheck`; `bun run test --run`; focused runtime/diagnostic
  tests.
