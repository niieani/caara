# Portable CLI contracts

Stabilize `caara agent start|wait|cancel` as a versioned typed boundary. Start accepts exactly one
of direct text, a UTF-8 file, or stdin and preserves the selected text verbatim. Target, working
directory, driver options, session identity, turn identity, prompt size, and wait bounds fail
explicitly rather than selecting defaults.

All success, nonterminal, terminal, and error results share contract version 1. Human rendering and
documented process statuses derive from those typed values; `--json` emits the machine form. The
HTTP adapter retains response status and closed error kind, so unavailable service, unknown state,
target rejection, invalid input, and concurrency are never inferred from prose.
