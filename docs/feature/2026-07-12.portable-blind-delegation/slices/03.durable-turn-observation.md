# Durable Turns and Observations

Replace process-local portable projections with explicit durable stores under Caara state. Persist
turn state and capability-linked observation records separately from session bindings and relay
logs. Terminal state is immutable. Recover completed observations and declared working-turn state
after service restart without using observation data to reconstruct external-agent sessions.

Use capability-indexed lookup without enumerable turn disclosure, Clock-based expiry, bounded
retention cleanup, and identical invalid/expired responses. Retention cleanup must never touch
session bindings. Verify storage schema/state transitions in process and restart/expiry/isolation
through compiled service-process tests, then all quality gates.
