# CAARA-cvvwwjqu

Implement recovery bypass for invalid-prompt driver failures.

Tests first:

- Claude resumed request with invalid driver option returns `response.failed` `invalid_prompt`
  instead of lost-session recovery text.
- Claude cwd-change/fresh recovery path does not mask invalid options.
- Antigravity resumed request with invalid driver option returns invalid-prompt failure instead of
  fresh recovery metadata/text.

Implementation:

- make recovery policies check `AgentDriverError.responseErrorCode`
- recover only explicit `server_error` lost-continuity failures
- preserve existing recovery for stale/resume continuity failures

Result:

- Claude resume query recovery now bypasses `invalid_prompt` and still recovers recoverable
  `server_error` stale-session failures.
- Claude cwd-change recovery fails invalid driver options directly, with no recovery metadata.
- Antigravity recovery helper recovers only `server_error` continuity failures; invalid prompt
  failures remain terminal.
- Added resumed-provider regression proving invalid Claude options emit `response.failed` and no
  lost-session recovery assistant text.
- validation: `bun lint`; `bun run typecheck`; `bun run test --run`; `bun run fmt`; focused
  recovery tests.
