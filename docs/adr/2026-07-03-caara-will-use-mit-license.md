# Caara will use the MIT license

Caara will use the MIT license when the repository is made public, even though the referenced
imagegen release project uses Apache-2.0. The trade-off is a shorter, familiar permissive license
without Apache-2.0's explicit patent grant; release implementation should add the root `LICENSE`
file before publishing assets or updating the Homebrew tap. The MIT copyright holder is
Bazyli Brzóska.
