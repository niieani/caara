Claude Code and Antigravity, running as native Codex subagents.

Caara is an OpenAI Responses–compatible bridge. Codex spawns a subagent; Caara starts or resumes the real external agent behind it and streams everything back — text, reasoning, activity — as if it were just another model. One session, every frontier mind you pay for.

Why panels

One model is a ceiling.
A panel is a lever.

OpenRouter's Fusion experiment measured it: synthesize the work of multiple models and you beat every single frontier model — including the strongest one on the panel. Caara brings that result into your terminal. Your Codex session is the orchestrator; Claude Code, Antigravity, and native Codex seats are the panel.

Native subagents, not glue scripts

Caara speaks the Responses subagent transport Codex already uses. External agents stream text and reasoning live, resume across turns with their own session cursors, and cancel cleanly when Codex disconnects. To Codex, claude/fable is just a model.

Validate with a second mind

Ship a diff, then have an agent from a different model family tear it apart. Self-review is biased by construction; cross-family review catches the blind spots a single model architecturally cannot see.

Fable, without the sticker shock

Claude Fable is the strongest — and priciest — seat at the table. Use it where judgment matters and delegate execution to cheaper seats. A panel with Fable in it beats Fable alone, and costs less than Fable doing everything.

Every subscription, fully used

Caara drives the agent binaries you already pay for — Claude Code on your Claude plan, Antigravity on yours. No new API keys, no per-token metering, no middleman cloud. Your idle subscription capacity becomes compute.

Explicit by design

Malformed requests, unknown drivers, invalid options, unresumable sessions — every failure is loud and typed. No silent fallbacks, no quiet degradation. Built with Effect on Bun, and smoke-testable end to end via a built-in diagnostic driver.

Open source & local-first

MIT-licensed. Runs as a per-user service on 127.0.0.1 — your prompts and code never route through a third party. Install with Homebrew, inspect every line, or build the single-file executable yourself.

Architecture

How it works

Codex sends a streaming POST /v1/responses. Caara resolves the model prefix to a driver, starts or resumes that agent's own session, and relays normalized runtime events back as Responses SSE frames.

Codex managing agent
POST /v1/responses · SSE
caara bridge · 127.0.0.1:8787
normalized runtime events
Claude Agent SDKclaude/* Antigravity CLIagy/* Diagnosticdiagnostic/*

The whole contract is a model string

// prefix picks the driver; suffix is driver-owned
{
  "model": "claude/fable",
  "input": "Review this diff for regressions.",
  "stream": true
}

Provider query params become driver options — effort, permission posture, tool allow/deny lists, budgets. Unknown options fail loudly.

Plug it into Codex once

[model_providers.caara]
name = "Caara Responses"
base_url = "http://127.0.0.1:8787/v1"
wire_api = "responses"
requires_openai_auth = false
query_params = { effort = "high" }

Or skip this entirely — caara install-service generates ready-made Codex agent roles for every driver it finds on your machine.

  • Durable session bindings — follow-up turns resume the agent's own conversation
  • Streams assistant text, reasoning summaries, and live activity commentary
  • Cancels in-flight driver work the moment Codex disconnects
  • Sandbox & effort signals from Codex forwarded as advisory driver input
  • Dangerous permission bypasses are double-gated: per-request and per-server opt-in

The skill pack

Panel — deliberation as a primitive

Caara ships with Panel, a Codex skill that convenes a cross-model panel of subagents and adjudicates the result. Pick a strategy — or let it pick one by the risk you're insuring against.

01

Ensemble

insures against omission

Isolated panelists attempt the same task in parallel — cold, quarantined, unable to peek at each other — then a synthesis seat consolidates. Catches what any single model would miss.

02

Debate

insures against contested direction

Panelists see each other's positions across rounds and argue toward a stronger shared answer. Dissent is preserved, capitulation without cause doesn't count as progress.

03

Cross-review

insures against self-bias

One panelist produces the work; a panelist from a different model family reviews it. The cheapest strategy — two seats, three turns — and the end of self-review theater.

Engineered against sycophancy

Opaque handlesThe orchestrator never reads panelist artifacts — it verifies them mechanically. No pre-biased adjudication.
Neutral forwardingPositions travel between panelists as artifact paths, never paraphrase. Paraphrase leaks preference.
The stall testA debate round only counts if a position changed with a cited cause. Two stalled rounds force a verdict with open items.
Quarantined runsPer-seat opaque directories, hidden from git and search, so independent seats stay independent.

Quickstart

Running in two minutes

  1. 1

    Install

    brew install --cask niieani/tap/caara

    Installs the signed binary, sets up the per-user service on 127.0.0.1:8787, runs doctor --fix, and health-checks it. macOS (Apple Silicon) and Linux tarballs on GitHub Releases.

  2. 2

    Roles appear automatically

    ls ~/.codex/agents/caara-*.toml
# caara-claude-fable · caara-claude-sonnet · caara-agy-gemini-3-5-flash · …

    The installer detects claude and agy on your machine and generates a Codex agent role for each model — updates preserve your tweaks, stale roles get cleaned up.

  3. 3

    Delegate — or convene a panel

    # inside Codex
> spawn a caara-claude-fable subagent to redesign the settings page
> use the panel skill: cross-review my last diff

    Follow-up turns resume the same external session. caara status and caara doctor keep the service observable.

Sessions & state

Session bindings are keyed by external agent kind + Codex thread id and hold resume metadata only — the external agent stays the source of truth for its own conversation. Drivers own opaque resume cursors; Caara persists them without interpreting them. If a session can't be resumed, the agent asks the managing agent to restate context — never a silent reset.
